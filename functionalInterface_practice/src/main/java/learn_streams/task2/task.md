## Задание 2. Композиция функций и каррирование
### Контекст
Функциональные интерфейсы можно комбинировать. У `Function<T, R>` есть методы `andThen` и `compose`, которые позволяют строить цепочки преобразований.<br> 
**Каррирование** (currying) — это техника, когда функция с несколькими аргументами превращается в последовательность функций с одним аргументом. 
Это помогает создавать гибкие конфигурации.

Задача
Напиши утилитный класс `FunctionUtils` со статическим методом:
```text
static <T, U, V> Function<T, V> chain(Function<T, U> first, Function<U, V> second) 

— возвращает композицию двух функций (это аналог first.andThen(second)).
```
Реализуй каррированную версию функции сложения трёх чисел:
```text
Function<Integer, Function<Integer, Function<Integer, Integer>>> add = ...

То есть add.apply(1).apply(2).apply(3) должно дать 6.
```

Используя эту каррированную функцию, создай префиксную функцию:

`add5` — прибавляет 5 к одному числу.

`add5and10` — прибавляет 5, а потом ещё 10 (по сути `add5.andThen(add10)`).
Покажи примеры их использования.

Дополнительно (по желанию): Напиши метод `curry3(BiFunction<T, U, V> biFunc)`, который принимает обычный `BiFunction`<br>
и возвращает каррированную версию `Function<T, Function<U, V>>`.

Вопросы для размышления
Как `andThen` и compose влияют на читаемость кода?

В каких ситуациях каррирование может упростить код, а в каких — сделать его излишне сложным?
