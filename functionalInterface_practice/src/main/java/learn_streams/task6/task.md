### Задача F1. Преобразование строк
Дан список строк.<br>
Напиши метод `List<String> transformStrings(List<String> strings, Function<String, String> transformer)`,
который применяет `transformer` к каждому элементу.

Затем в main продемонстрируй:
- Преобразование всех строк в верхний регистр.
- Удаление пробелов в начале и конце (`String::trim`).
- Добавление префикса `"Prefix: "` к каждой строке.

**Вопрос: Как использовать одну и ту же функцию для разных преобразований? Как передать в transformer лямбду или ссылку на метод?**
