### Задача R4. Свой Stream (упрощённая версия) — доделать ленивость
Вспомни задание 5 из предыдущего блока. Ты уже начал реализовывать свой `SimpleStream`.

Теперь добавь ленивость:
- Методы `filter` и `map` не должны выполнять операции сразу, а запоминать их (например, в списке операций).
- Терминальные операции (`forEach`, `toList`) запускают выполнение всех накопленных операций над исходными данными.
- Покажи, что при вызове `filter(...).map(...).forEach(...)` преобразования происходят только внутри `forEach`, а не раньше.
