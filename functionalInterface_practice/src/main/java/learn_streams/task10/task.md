### Задача R2. Универсальный кэш с Function
Создай класс `Cache<K, V>`, который хранит вычисленные значения. Конструктор принимает `Function<K, V> calculator` — функцию, которая по ключу вычисляет значение.
Метод `V get(K key)` должен:
- Если значение для ключа уже есть в кэше (например, в Map<K, V>), вернуть его.
- Если нет — вычислить через calculator.apply(key), сохранить в кэш и вернуть.

Проверь, что повторный вызов с тем же ключом не вызывает `calculator` повторно.

<summary>🔽 Усложнение</summary>
Сделай потокобезопасную версию (используй ConcurrentHashMap и computeIfAbsent).
</details>
