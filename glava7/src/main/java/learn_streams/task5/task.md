## Задание 5. Свой Stream (упрощённая версия)
### Контекст
`Stream API` — один из главных потребителей лямбд. Понимание того, как работают промежуточные и терминальные операции, поможет глубже освоить API.<br>
Создание мини-версии стрима — отличная практика.

### Задача
Реализуй свой класс `SimpleStream<T>` с возможностью:

Конструктор, принимающий `List<T>`.

Метод `SimpleStream<T> filter(Predicate<T> predicate)` — возвращает новый `SimpleStream`, содержащий только элементы, прошедшие фильтр.

Метод `<R> SimpleStream<R> map(Function<T, R> mapper)` — возвращает новый `SimpleStream` с преобразованными элементами.

Метод `void forEach(Consumer<T> consumer)` — применяет действие к каждому элементу (терминальная операция).

Метод `List<T> toList()` — собирает элементы в список (терминальная операция).

**Важно**: операции `filter` и `map` должны быть ленивыми. Это значит, что они не выполняют преобразования сразу, а сохраняют информацию о том, что нужно сделать.<br>
Реальное выполнение происходит только при вызове терминальной операции (`forEach`, `toList`). Для этого можно хранить внутри `SimpleStream` исходные данные и список операций 
(например, список `Function<List<T>, List<T>>`), но это упрощённый вариант.<br> 
Более продвинутый подход — реализовать итератор, который применяет операции на лету.

### Требования:

**Продемонстрируй цепочку:**
```java
new SimpleStream<>(List.of(1,2,3,4,5))
.filter(x -> x % 2 == 0)
.map(x -> x * x)
.forEach(System.out::println); // должно вывести 4, 16
```
Убедись, что в примере выше фильтрация и маппинг выполняются во время вызова `forEach`, а не при вызове `filter` или map.
