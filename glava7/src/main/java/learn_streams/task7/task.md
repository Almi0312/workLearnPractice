### Задача F2. Композиция функций в реальном примере
У тебя есть класс `User` с полями `String name, int age`.

Нужно:
- Написать функцию `Function<User, String>` которая возвращает имя в верхнем регистре.
- Написать функцию `Function<String, Integer>` которая возвращает длину строки.
- Создать композицию этих функций с помощью `andThen` и применить к объекту `User`, чтобы получить длину имени, приведённого к верхнему регистру.
- Проделать то же самое с помощью compose (порядок должен быть обратным — сначала получить длину, потом… но это не имеет смысла, так что просто покажи, что compose меняет порядок).

#### Дополнительно:
Напиши универсальный метод `<T, U, V> Function<T, V> compose(Function<T, U> f, Function<U, V> g)` — аналог `g.compose(f)`.
