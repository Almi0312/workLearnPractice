## Задача 2. Логирование в файл и в консоль (Паттерн Decorator)

### Контекст (реальная ситуация):

Ты пишешь приложение, которое должно логировать сообщения. Требования меняются:

- Сначала нужно было только писать в консоль.
- Потом добавили запись в файл.
- Затем захотели одновременно и в консоль, и в файл.
- Ещё позже — добавлять временную метку перед сообщением или уровень важности (ERROR, INFO).

Плохое решение: создать классы `ConsoleLogger`, `FileLogger`, `BothLogger`, `TimestampConsoleLogger`,
`TimestampFileLogger...`<br>
Количество классов взрывается.

### Задача:

Спроектируй систему, где ты можешь на лету комбинировать поведение:

- `new ConsoleLogger()` — пишет только в консоль.
- `new FileLogger("log.txt")` — пишет только в файл.
- `new TimestampDecorator(new BothLogger(new ConsoleLogger(), new FileLogger()))` — пишет и туда, и туда с временной
  меткой.

### Что нужно сделать:

- Базовый интерфейс `Logger` с методом `log(String message)`
- Конкретные компоненты: `ConsoleLogger`, `FileLogger`.
- Абстрактный декоратор `LoggerDecorator`, который хранит ссылку на `Logger`
- Конкретные декораторы: `TimestampDecorator`, `LevelDecorator` (добавляет [ERROR] / [INFO]).

### Подсказка:

Паттерн `Decorator` оборачивает один объект в другой, добавляя новое поведение, при этом они имеют общий интерфейс.
